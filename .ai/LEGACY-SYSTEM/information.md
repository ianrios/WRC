# repo info

- this is a javascript react app website for a record label passion project of mine that is used primarily as a front end only content management system and quick share EPK / linktree platform for the artists releases and their personas
- the app is tested locally for development via `npm run start`
- the app is deployed to firebase via `npm run deploy` and goes straight to production.
- we have full control over every aspect of the app and can write custom scss and redeploy as needed
