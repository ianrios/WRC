# Summary:

- Replace hamburger nav with an icon-based floating navigation.

# Constraints:

- Must work on desktop and mobile
- No borders or outlines
- Must be feature-flagged

# Acceptance criteria:

- Collapsed and expanded states
- Keyboard support (Tab, Enter, ESC)
- Mobile tap-to-open behavior
- Physics-based animation (phase 2)

# Non-goals:

- Visual parity with existing routing
- Gesture support beyond tap

# Status:

- Active
